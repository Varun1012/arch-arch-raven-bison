GitHub blocks first-time Pages enablement from API / Actions tokens. Turn it on once:

1. Open [Settings → Pages](https://github.com/Varun1012/arch-arch-raven-bison/settings/pages)
2. **Build and deployment → Source** → **GitHub Actions**
3. Open [Actions](https://github.com/Varun1012/arch-arch-raven-bison/actions) → latest **pages** run → **Re-run all jobs**

After that, every push to `main` deploys automatically.

## How to play

- **WASD / arrows** — move Hong Kong
- **Space** — Lee's Force Field (4 per season)
- **F** — trading halt, 5 seconds, once, last 4 minutes only  
  If Signal No. 8 or above is still in force when the halt ends, the season is over.

Hang Seng Index opens at 20,000. Signal No. 1 and up cause panic selling. Purple **devil storms** can spawn in the second half as super typhoons.

Viewport: 7–31°N, 105–140°E.
