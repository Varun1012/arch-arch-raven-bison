# 八號風球 / 暴風警報

Two maps, one season:

- **香港 · 八號風球** — move Hong Kong, Lee's Force Field, protect the Hang Seng Index from 20,000.
- **日本 · 暴風警報** — move the archipelago, コロッケ, protect the Nikkei from 60,000. UI is Japanese.

**Play:** [varun1012.github.io/arch-arch-raven-bison](https://varun1012.github.io/arch-arch-raven-bison/)

## How to play

- **WASD / arrows / joystick** — move the home marker
- **Shift / E** — flash dash, 3 seconds, 5 per season, 10s cooldown
- **Space** — Lee's Force Field / コロッケ (3 per season, cooldown)
- **F** — trading halt, 5 seconds, once, second half only  
  If Signal No. 8 / 暴風警報 or above is still in force when the halt ends, the season is over.
- **P / Esc** — pause

Hong Kong viewport: 7–31°N, 105–140°E. Japan viewport: 24–46°N, 124–150°E. Season: 3 minutes.

After the season ends, choose endless mode or close the market. Endless gets harder as time lapses.
